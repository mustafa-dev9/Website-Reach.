🚀 Reach — Creative Advertising & Design Agency

«Reach is a modern Arabic creative agency website designed to showcase advertising, printing, branding, and creative design services in a professional and visually engaging way.»

📌 About The Project

Reach is a responsive front-end website created for a creative advertising and design agency.

The website focuses on presenting the agency's services, previous work, customer testimonials, and contact information through a modern user interface.

The main goal of the project is to provide visitors with a clear overview of the agency and make it easy for potential clients to explore services and get in touch.

---

✨ Features

- 🎯 Modern landing page
- 📢 Advertising services section
- 🖨️ Printing services section
- 🎨 Creative design and branding section
- 🖼️ Portfolio / previous works section
- 💼 B2B and B2C service sections
- 🚀 Call-to-action sections
- ⭐ Customer testimonials
- 📞 Contact information
- 📱 Responsive design for different screen sizes
- 🔗 Social media links
- 🧭 Navigation menu
- 📧 Email subscription field
- 🎨 Custom visual design

The homepage contains sections for services, portfolio, assistance, a call-to-action, customer opinions, and a footer with navigation and contact information.

🎨 Website Sections

🏠 Home

The hero section introduces the agency and highlights its main value proposition, with calls to action for starting a project or learning more about the company.

💼 Services

The website presents three main services:

- Advertising
- Printing
- Creative Design

Each service includes a visual element, short description, and action button.

🖼️ Portfolio

A portfolio section showcases examples of previous projects, including:

- Corporate print design
- Outdoor advertising campaigns
- Printed identity and packaging

🤝 B2B & B2C

The website distinguishes between:

- B2B: Strategic business solutions for companies
- B2C: Creative services for individuals

This section is designed to guide different types of clients toward suitable services.

⭐ Client Testimonials

A dedicated section displays customer testimonials to showcase previous client experiences and build trust with visitors.

📞 Contact & Footer

The footer provides:

- Navigation links
- Contact information
- Email field
- Social media icons
- Location information

🚀 Getting Started

To run the project locally:

1. Clone the repository

git clone https://github.com/mustafa-dev9/Website-Reach.git

2. Open the project

Navigate to the project directory:

cd Website-Reach

3. Run the website

Open:

Home.html

in your browser.

You can also use VS Code + Live Server for a better development experience.
